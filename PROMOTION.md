### 正文

做了一个很小的 Agent Skill：**answer-with-words**，给 AI 加一个“词汇回答”模式。

启用后，回答通常只保留 **1–7 个关键词或短词组**；需要细节时，说“展开”“解释”或“正常回答”即可切换。

例如，问“如何提高阅读效率？”

> 明确目标、带着问题读、重点精读、主动回忆、间隔复习

适合头脑风暴、提炼关键因素、词汇问答游戏。规则已公开：保留必要限定；遇到创建文件、执行操作等任务，仍需完成实际交付。

项目：https://github.com/Martinqi826/answer-with-words

准备 Node.js 22.20+、npm 和 Git，在项目目录安装：

```bash
npx skills add Martinqi826/answer-with-words --skill answer-with-words
```

按提示选择客户端。已验证 Skills CLI 1.7.4 向 Codex、Claude Code 项目目录安装及文件完整性；尚未完成跨客户端的模型效果测试。

启用：

```text
使用 answer-with-words，仅用词汇回答接下来的问题。
```
