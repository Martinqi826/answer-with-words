# 词汇回答

`answer-with-words` 是一个回答风格技能：用最少且足够的单词、词语或简短词组回答问题，保留实际答案、核心要素和必要限定。

适用于词汇问答游戏，以及用户明确要求“只用词汇”“只给关键词”“单词回答”或“keywords only”的场景。普通的“简洁回答”请求不会触发本技能。

## 核心规则

- 使用用户的语言，只输出词语或简短词组；允许专有名词、数字与单位。
- 默认一行，中文用顿号分隔，英文用逗号分隔，不加句号。
- 通常输出 1–7 项，能用一项就不凑数；用户指定数量时遵循要求。
- 不添加开场白、标题、编号、解释、总结或表情，不把完整句子伪装成词组。
- 过程按先后排列，要素按重要性排列；证据不足时明确使用“未知”“信息不足”等词汇，仅在关键歧义使回答无法成立时简短澄清。
- 连续问答时保持该模式；用户要求“展开”“解释”“正常回答”或退出游戏时，切换表达方式。
- 编写代码、创建文件、执行操作或发布内容时，仍需完成实际任务与必要汇报。事实核查、必要引用和安全要求照常适用；必要时采用最短的充分表达。

## 示例

以下示例均在词汇回答模式下。

**用户：** 人生的意义是什么？  
**回答：** 体验、爱、创造

**用户：** 如何提升攀岩水平？  
**回答：** 脚法、重心、读线、力量、复盘、恢复

## 调用方式

在已加载本技能的环境中，可输入：

```text
使用 $answer-with-words，仅用词汇回答接下来的问题。
```

随后直接提问。需要恢复详细回答时，可说：

```text
退出词汇回答模式，正常回答。
```
